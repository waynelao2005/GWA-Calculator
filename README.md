# GWA Calculator

This is a simple single-page GWA calculator for college students. It lets the user add subjects, enter units and grades, and see the weighted average update instantly.

## Run locally
1. Open this folder in VS Code.
2. Start the project with Live Server.
3. Open the served page in the browser.

Note: ES modules do not work correctly when the page is opened directly as a `file://` URL, so Live Server is the recommended way to run it.
